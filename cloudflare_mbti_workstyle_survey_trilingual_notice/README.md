# 团队沟通偏好自评（Cloudflare 部署包）

这是一个原创的 104 题问卷，参考 MBTI 常见的四组偏好维度来帮助同事讨论沟通方式。它**不是官方 MBTI® 问卷**，没有声称经过心理测量学验证，也不能替代正式评估。

## 功能
- 104 道原创陈述，5 点同意度量表，自动显示个人四字母偏好轮廓及协作建议
- 匿名提交
- 管理员口令保护团队汇总：四维平均倾向、16 种组合数量
- 不要求姓名、邮箱或部门；允许重复提交

## 部署步骤
1. 在 Cloudflare Dashboard 创建 **D1 Database**。
2. 打开 D1 Console，执行 `schema.sql` 中全部 SQL。
3. 编辑 `wrangler.jsonc`，把 `database_name` 和 `database_id` 替换为你新建数据库的真实值。
4. 安装 Node.js，然后在此文件夹打开终端运行：
   - `npx wrangler login`
   - `npx wrangler secret put ADMIN_PIN`，按提示输入一个足够长的管理员口令
   - `npx wrangler deploy`
5. 部署成功后，Cloudflare 会显示 `workers.dev` 地址。把地址发给同事填写。

## 计分说明
- 104 题按四组偏好维度设计，每个维度两端各有陈述。
- 受试者选择 1–5（非常不同意到非常同意），部分题目反向计分。
- 结果显示四组偏好相对比例，生成类似四字母的探索性轮廓。它只是团队沟通讨论的起点，并非诊断或官方 MBTI 类型。
- 由于这是原创简化问卷，未经正式信效度验证，不应当作招聘、晋升、绩效评估或人员筛选依据。

## 隐私与安全
- 页面不询问姓名、邮箱或部门，但数据库会存答题内容、提交时间和计算出的偏好轮廓。
- 管理员口令用 Cloudflare Secret 保存，不写入公开 HTML。
- 公开链接允许重复提交；统计按每次提交计数。
- Cloudflare 可能处理运行服务所需的技术日志，不能承诺绝对不可追踪。
